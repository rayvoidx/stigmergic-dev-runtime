# TrendEvoBench

Synthetic trend-selection benchmark for the stigdev runtime. Artifacts
implement `select_trends(items: list[dict], k: int) -> list[str]` over items
with public fields `id, text, source, ts, engagement`; the evaluator holds the
truth fields (`relevant`, `dup_group`) and scores
`0.7 * precision@k + 0.3 * unique_dup_group_rate` per split.

All data is generated by `generate_fixtures.py` (seeded, no real platform
content). Committed fixture versions are immutable — change scoring-relevant
content only by adding a new version directory.

## v1 — mechanism tier

Small landscape used by the deterministic demo and most tests. Traps:
clickbait keywords, shared-prefix near-duplicates, stale items, keyword-
bearing hype. The offline provider's genes were tuned against it; it
saturates quickly (seed 0.55 -> 0.86 train with three simple improvements),
which is fine for exercising promotion/rejection/replay but too easy for
comparisons.

## v2 — discrimination tier

Built so simple heuristics get partial credit and only combined reasoning
approaches the ceiling. Adversarial properties (locked in by
`tests/test_fixtures_v2.py`):

- **Paraphrased duplicates** — same story rendered with different lead words;
  40-char normalized-prefix dedup gains exactly nothing. Token-overlap
  (e.g. Jaccard) reasoning is required.
- **Subtle listicle spam** — high engagement, no clickbait vocabulary, no
  target keywords; the `source` field (feed reliability skew) is the usable
  signal.
- **Old-but-relevant analysis items** — aggressive recency decay backfires.
- **Relevant items skew low/mid engagement** — engagement is an anti-signal.

Calibration (measured 2026-08-30, evaluator v1, k=10):

| probe artifact | train | holdout |
|---|---|---|
| seed (engagement only) | 0.30 | 0.37 |
| v1 gene: prefix dedup | 0.30 | 0.37 |
| v1 gene: recency | 0.37 | 0.58 |
| v1 gene: keyword | 0.69 | 0.83 |
| v1 genes dedup+recency+keyword | 0.69 | 0.80 |
| `reference_artifact_v2.py` (probe) | 0.97 | 0.90 |

`reference_artifact_v2.py` is a calibration probe proving the ceiling is
reachable (source weighting + token-overlap dedup + keyword evidence + gentle
recency); runs still start from `seed_artifact.py`. The holdout split is
somewhat easier than train at the keyword rung (0.83 vs 0.69) — known
asymmetry, single-digit item counts per trap category; do not over-read
per-split gaps.
