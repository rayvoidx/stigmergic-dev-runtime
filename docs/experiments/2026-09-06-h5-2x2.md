# Lab note: H5 2x2 — capability x coordination-medium interaction (2026-09-06)

The pre-registered H5 test (registered 2026-08-31 at commit `6327f7b`):
does the advantage of `artifact_only` over `single_persistent` grow with
worker capability?

**Registration honesty:** H5 was registered after seeing the gpt-oss n=5
pilot but before the gpt-oss n=20 extension and before all gemma3 seeds
46–60. The gemma3 extension arm is therefore the only fully novel data;
call this a *registered, partially confirmatory* test, not a clean
pre-registration. Server-version confound: gemma3 ran on Ollama 0.31.2
(app), gpt-oss on 0.33.2 (standalone) — constant within cells, confounded
with model across cells.

## Design

2 models x 2 conditions x 20 seeds (41–60) = 80 runs, matched budgets
(6 episodes, temperature 0.7, fixtures v2, k=10), all local, $0.
**All 80 runs replay with 0 divergences.** Data (per-run values + cells +
interaction bootstrap): `docs/experiments/data/h5-2x2-n20.json`.

## Cells (holdout mean [bootstrap 95% CI], sd, n=20)

| | artifact_only | single_persistent |
|---|---|---|
| **gemma3:12b** (weaker) | 0.494 [0.425, 0.567], sd 0.164 | **0.664** [0.595, 0.730], sd 0.157 |
| **gpt-oss:20b** (stronger) | **0.799** [0.776, 0.819], sd 0.049 | 0.767 [0.727, 0.800], sd 0.090 |

## Registered interaction test

Delta = (AO − SP)_strong − (AO − SP)_weak on holdout.
Point estimate **+0.202**, bootstrap 95% CI **[0.093, 0.310]** (10k
resamples) — CI excludes 0 in the registered direction. **H5 supported** on
this benchmark/model pair.

## Reading

1. **The interaction is real on this setup.** With the weaker worker,
   persistent private context wins outright at n=20 (cell CIs no longer
   overlap: 0.664 vs 0.494). With the stronger worker, ephemeral stigmergic
   workers match it (0.799 vs 0.767, overlapping) with roughly half the
   variance.
2. Thesis framing this supports (still limited to one toy benchmark and one
   model pair): persistent conversational identity is a *crutch whose value
   shrinks with worker capability* — strong workers coordinate as well
   through the selective persistent medium alone. It does NOT support
   "stigmergy beats persistence" in general; at gpt-oss scale the result is
   parity, not victory, and at gemma3 scale persistence wins.
3. Caveats: single benchmark family; model confounded with runtime version;
   capability operationalized as just two models; temperature 0.7 only;
   equivalence at the strong end unregistered (no TOST bound).
